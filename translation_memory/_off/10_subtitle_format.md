# Subtitle Rules

FORMAT:
- Keep subtitle short.
- Avoid long sentences.
- One subtitle should be readable quickly.

RULE:
If one Chinese sentence is too long: split meaning naturally, but STILL return exactly ONE Vietnamese line per source line (do not change line count / numbering).

Example:
Chinese: 他为了保护家人隐藏身份十年
Vietnamese: Anh ấy đã giấu kín thân phận suốt 10 năm để bảo vệ gia đình.

Do not create: a very long rambling Vietnamese sentence.
