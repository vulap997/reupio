# Wuxia Xianxia Rules

CONTEXT:
Ancient Chinese fantasy, cultivation, martial arts.

KEEP TERMS:

修仙 = tu tiên
渡劫 = độ kiếp
灵力 = linh lực
灵气 = linh khí
筑基 = Trúc Cơ
金丹 = Kim Đan
元婴 = Nguyên Anh
飞升 = phi thăng
宗门 = tông môn
秘境 = bí cảnh
师尊 = sư tôn
师兄 = sư huynh
师妹 = sư muội
掌门 = chưởng môn
仙帝 = tiên đế

RULE:
- Keep fantasy atmosphere.
- Do not replace traditional terms with modern words.
